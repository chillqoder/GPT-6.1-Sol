Create a single-file HTML game using Three.js that is a 3D low-poly interpretation of Super Mario Bros. Level 1-1. The game should feature a procedurally generated stylized environment (e.g., a low-poly grassy platformer landscape with hills, bushes, and clouds in the background). The main character, a low-poly plumber built from basic shapes, must be controllable with left/right movement (arrow keys or A/D) and run across the level. Implement jumping mechanics (spacebar input) to leap onto platforms, bounce on question-mark blocks, and avoid or stomp on obstacles like low-poly enemies (e.g., simple mushroom-shaped "goombas") and gaps/pits. As the player progresses, coins should be collectible and a score/coin counter should be displayed in the corner, along with a simple timer. Use a vibrant, stylized color palette (bright blues for sky, greens for pipes and ground, warm browns for blocks) with soft lighting to give it a modern aesthetic. The entire code must be contained within one HTML file, including the Three.js library via CDN, and it must handle window resizing.
