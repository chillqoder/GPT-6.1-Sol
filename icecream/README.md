# Scoop Studio

A single-file, responsive Three.js ice cream playground created from `obj.md`.

Open `index.html` in a modern browser, or serve this folder locally:

```sh
python3 -m http.server 8766
```

Then visit <http://localhost:8766>.

Pick strawberry, pistachio, or vanilla; turn the sprinkles and rotation on or off; change the drizzle speed; and press **Make it melt** for faster glaze and falling droplets. Drag the dessert to rotate it, or focus it and use the arrow keys. **A fresh start** resets the scene.

The cone, raised waffle lattice, scoops, swirls, animated chocolate cap, cherry, sprinkles, plate, and particles are generated in code. No model or image assets, build process, or dependencies to install. Three.js 0.180.0 and fonts load from CDNs, so an internet connection is required. The scene respects reduced-motion preferences and includes keyboard controls.
